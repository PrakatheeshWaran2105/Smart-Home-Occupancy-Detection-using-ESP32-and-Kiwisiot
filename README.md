# Smart Home Occupancy Detection Using ESP32 and KiwisIoT

## About the Project

The **Smart Home Occupancy Detection Using ESP32 and KiwisIoT** is an IoT-based smart home monitoring project designed to detect human presence in a room.

Using an ESP32 microcontroller and an occupancy detection sensor, the system identifies whether someone is present in a particular area and sends real-time status updates to the KiwisIoT platform through Wi-Fi.

Users can remotely monitor room occupancy through the KiwisIoT dashboard. This project demonstrates how KiwisIoT can be used to develop smart home automation and intelligent occupancy monitoring solutions.
